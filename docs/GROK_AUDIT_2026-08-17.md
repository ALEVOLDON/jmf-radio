## 1. Вердикт

JMF Radio — сильный персональный проект с характером: локальная радиостанция поверх папки с музыкой плюс 3D-ночной клуб и HTML-пульт в эстетике Pioneer CDJ / DJM.

За полтора дня получился не «ещё один плеер», а целая атмосфера. Под капотом это пока **эффектный прототип**, а не hardware-faithful эмулятор CDJ-3000, как обещает README.

**Слушать и крутить камеры — да. Называть это Pioneer-станцией — нет.**

Опасная точка проекта: **оболочка обогнала машину**. Пульт выглядит как железо, внутри — два `HTMLAudioElement`, процедурные волны и половина кнопок-муляжей. Если наращивать ещё больше UI, останется музей кнопок. Если сузить обещание и добить ядро — получится вещь, к которой хочется возвращаться каждый вечер.

## 4. Что реально работает и это надо беречь

Не ломать при рефакторинге.

### 4.1 Аудио-граф

В `AudioEngine.initAudioContext()` настоящая цепочка на каждый дек:

`MediaElementSource → EQ low/mid/high → filterSweep → chGain → xFaderGain → masterGain → analyser → destination`

Живое:

- 3-полосный EQ (`lowshelf` 120 Hz, `peaking` 1 kHz, `highshelf` 8 kHz)
- Color-фильтр LPF ↔ HPF через `setFilterSweep`
- Equal-power кроссфейдер (`cos` / `sin`)
- Auto Mix ~8 с с «bass swap» (фильтр на уходящем/входящем)
- Channel fader / trim через `setChannelGain`
- Pitch fader → `playbackRate`
- 4/8 beat loop через `currentTime` rewind
- Cue на `cueTime` (сейчас всегда 0)
- Seek по клику на волну
- Jog: drag-seek ≈ 1.8 с на оборот + wheel nudge ±0.35 с
- EQ-пресеты Radio Mode: FLAT / BASS BOOST / CLUB / VOCAL / ELECTRONIC
- Старт через overlay `ENTER CLUB` (autoplay policy)

### 4.2 3D-клуб

Процедурная сцена собрана аккуратно и звукореактивна:

- 8 камер, включая POV (прячет торс DJ) и cinema orbit
- 4 цветовые темы
- Строб / лазеры / «fog»-частицы + слайдеры яркости и скорости
- Сабы с ходом диффузора
- Бармен, танцпол 6×6, ~12 танцоров, VIP, неон, skyline
- Сценический экран 1024×512, 5 VJ-режимов, трек/артист/жанр
- Ноутбук DJ рисует спектр на canvas-текстуре

### 4.3 Сервер как домашняя станция

- Рекурсивный скан аудиорасширений
- Range / 206 streaming
- Кэш `genre_library_cache.json`
- Shuffle, очередь из 6 треков, history
- Обложки из ID3 (`/api/cover/:id`)
- Жанровый фильтр AutoDJ

### 4.4 Продуктовые решения, которые верные

- Radio Mode по умолчанию на `innerWidth <= 820` и UA mobile
- Вкладки DECK A / MIXER / DECK B на узком экране
- Мобильный drawer с камерами, жанрами, светом, EQ
- Разделение «послушать» и «покрутить пульт»

## 6. Баги и мёртвый код

Идентификаторы стабильные. При закрытии ставить `[x]` и коротко писать, что сделано.

### G-01 · `fetchStatus()` не существует

- **Файл:** `src/audio/AudioEngine.js` (~строка 546)
- **Суть:** `setGenre()` после успешного `POST /api/genre/select` делает `await this.fetchStatus()`. Метода нет.
- **Эффект:** смена жанра падает в `catch`, очередь/лейблы могут не обновиться. Ошибка глотается `console.warn`.
- **Фикс:** реализовать `fetchStatus()` (повтор `GET /api/track` + обновление `currentTrack` / `queue` / `nextTrack`) либо убрать вызов и явно обновить состояние из ответа `select`.

### G-02 · Двойной `POST /api/skip`

- **Файл:** `server.js` (~473 и ~576)
- **Суть:** первый хендлер идёт в паре с `/api/next` и уважает жанровый фильтр. Второй — просто `(currentIndex + 1) % length`.
- **Эффект:** в Express побеждает первый. Второй — мёртвый код и ловушка при правках.
- **Фикс:** удалить второй. Оставить один канонический skip.

### G-03 · Два независимых «сейчас играет»

- **Файлы:** `server.js` (`trackStartTime` + `checkTrackAdvancement` раз в 1 с), `AudioEngine.js` (свой `HTMLAudioElement`, почти без поллинга `/api/status`)
- **Суть:** сервер тикает по своей `duration` (часто оценка `filesize / 24KB`). Клиент играет реальный файл и сам зовёт `/api/next` в конце или на skip.
- **Эффект:** у хоста и у гостя разные треки; сервер может переключить очередь, пока клиент ещё слушает.
- **Фикс:** выбрать одну модель:
  - **A. Клиентский плеер** — сервер только библиотека + next. Убрать серверный auto-advance.
  - **B. Настоящее радио** — сервер шлёт live-позицию, клиенты синкаются к `elapsed`. Нужен poll/websocket.
- Сейчас это ни A, ни B.

### G-04 · Глобальный стейт на всех слушателей

- **Файл:** `server.js` (`playlist`, `currentIndex`, `activeGenreFilter`)
- **Суть:** один индекс на процесс. `/api/skip`, `/api/prev`, `/api/genre/select`, `/api/rescan` без auth.
- **Эффект:** гость по туннелю крутит станцию всем.
- **Фикс минимум:** read-only для анонимов, write — секрет/localhost.  
  **Фикс нормально:** сессии на клиента (у каждого своя очередь) *или* явный «один эфир» + роль DJ.

### G-05 · `.env` не загружается

- **Файлы:** `.env.example`, `package.json`, `server.js`
- **Суть:** нет `dotenv`. `process.env.MUSIC_DIR` / `PORT` работают только если их выставил shell. `DJ_CROSSFADE_SECONDS` и `RADIO_CROSSFADE_SECONDS` сервер игнорирует. `start-radio.bat` зашивает `D:\Soundcloud` в echo и не читает `.env`.
- **Фикс:** `dotenv` при старте **или** явный парсер `.env`. Батник берёт `MUSIC_DIR` оттуда же.

### G-06 · Длительность трека часто фейковая

- **Файл:** `server.js` `getTrackMetadata()`
- **Суть:** `music-metadata` с `duration: false` и таймаутом 400 мс. Fallback: `stat.size / (24 * 1024)`, clamp 60–3600. Кэш пишется через `setTimeout(saveGenreCache, 2000)` сразу после скана, до ленивого парса большинства файлов.
- **Эффект:** кривой прогресс, ранний/поздний auto-advance на сервере, в очереди «3:00» у всего.
- **Фикс:** парсить duration нормально (воркер/очередь), кэшировать после каждого успешного parse, не оценивать bitrate «на глаз».

### G-07 · `hasCover` всегда false

- **Файл:** `server.js`
- **Суть:** поле отдаётся в `/api/status`, но нигде не выставляется в `true`. Обложка есть только если клиент сам сходит на `/api/cover/:id`.
- **Фикс:** при parse смотреть `common.picture` (можно без сохранения байтов) и ставить флаг.

### G-08 · Jog / overlay / play state расходятся

- **Файлы:** `UIController.js`, `AudioEngine.js`
- **Суть:**
  - CUE всегда прыгает в 0 — `cueTime` никогда не пишется с текущей позиции.
  - `togglePlayDeck` на standby-деке не делает его `activeDeck`, но крутит звук «под» кроссфейдером (у B стартовый xFaderGain = 0 — можно «играть тишину»).
  - Overlay `#start-overlay` обязателен: без клика Autoplay блокирует звук. Это ок, но нет повторного CTA, если `play()` упал.
- **Фикс:** CUE set/jump как на CDJ; play на деке без фейдера — либо поднять gain, либо не стартовать; ошибку autoplay показать в UI.

### G-09 · `setLasersEnabled` гасит не лазеры

- **Файл:** `src/scene/Lighting.js`
- **Суть:** выключатель «Moving Head Lasers» прячет `danceFloorSpot`, не `laserBeams` / `laserGroup`.
- **Фикс:** `laserGroup.visible = enabled`. Спот танцпола — отдельный тоггл или всегда живой.

### G-10 · Мёртвый импорт и мёртвые модели

- **Файлы:** `src/scene/DJCharacter.js` (`GLTFLoader`), `public/models/*.glb`, копии в `dist/models/`
- **Суть:** три GLB готовы, сцена их не грузит. Бандл тащит неиспользуемый loader.
- **Фикс:** загрузить GLB в `DJScene` / подсистемы **или** убрать импорт и честно оставить примитивы. Не держать оба мира молча.

## 9. Архитектурный долг (не баги, но мешает расти)

1. **God-файлы:** `UIController.js`, `index.html`, `style.css`, `server.js`. Новый FX = правка сразу в трёх местах.
2. **Нет модулей пульта:** дек / микшер / radio console / lighting modal должны стать отдельными контроллерами.
3. **Нет типов.** Хотя бы JSDoc на публичные методы `AudioEngine` (`setEQ`, `setFilterSweep`, `triggerDJCrossfade`).
4. **Нет тестов.** Минимум: classifyGenre fixtures, crossfader gain на 0/0.5/1, range-stream 206, path не утекает наружу.
5. **Dev-контур:** `vite.config.js` проксирует `/api` на `:3000`, но `npm start` отдаёт только `dist`. Правка фронта без `npm run build` в проде не видна. Это надо явно написать в README: `npm run server` + `npm run dev`.
6. **Перф 3D:** shadows + много Point/Spot + 450 частиц + 12 персонажей + canvas-текстуры каждый кадр. На телефоне Radio Mode прячет пульт, но сцена всё равно рендерится. Нужен lod / пауза сцены в radio / `setPixelRatio` уже ограничен 2 — этого мало.
7. **`user-select: none` на `*`** в CSS — ломает копирование названия трека. Сузить селектор.
8. **Дубли `dist/` в git.** Сборка закоммичена вместе с исходниками. Либо игнорировать `dist`, либо осознанный release-артефакт. Сейчас оба мира расходятся.
9. **`genre_library_cache.json` с абсолютными Windows-путями.** Кэш непереносим на другую машину/букву диска.

## 10. Безопасность и деплой

Для дома за LAN — приемлемо. Для «шарь ссылку» — нет.

| Риск | Где | Что будет |
|---|---|---|
| CORS `*` | `server.js` + заголовки стрима | Любой сайт может дергать API |
| Write API без auth | `/api/skip`, `/api/next`, `/api/prev`, `/api/genre/select`, `/api/rescan` | Любой слушатель = DJ |
| Полная библиотека по id | `/api/stream/:id`, `/api/cover/:id` | Кто знает URL, качает всю папку |
| Туннель в README | ngrok / cloudflared / loca.lt | Ссылка протухает; пока жива — открытый пульт |
| `cloudflared.exe` в корне диска | gitignored, на диске есть | Ок, что не в git. Не коммитить |

Минимальный контур «показать друзьям»:

- GET публичные, POST только `X-DJ-Key` или loopback
- Не писать в README живой туннель как «permanent demo»
- Не класть `.exe` в репозиторий (уже соблюдено)
